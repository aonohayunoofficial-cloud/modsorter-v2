## 小分類

- [x] 風車(`wind_turbine`) — 水平軸2形式＋垂直軸4形式の計6形式。
  近代（水平軸）は2,000kW級でタワー高さ78m・タワー直径4.3m（頂部は基部-2）・
  ローター直径86m、ナセルは長さ10.4m・幅3.5m・輸送時高さ4m（設置時5.4m）。
  ハブ高さ60〜100m・翼端到達高100〜150m。翼端が地面へ潜らないようローター直径は
  ハブ高さの2倍-4で自動的に抑える。
  オランダ型は下太りの塔身＋ドームのキャップ＋外周ギャラリー。羽根は縦框（whip）と
  帆桟を全ブロックで通し、帆布だけフェンスにする（従来は縁と桟だけの格子で羽根が
  透けていた）。既定のブロックは木造。
  垂直軸は ダリウス（φ型）／直線翼（H型・ジャイロミル）／ヘリカル（ねじり直線翼）／
  サボニウス（S型ロータ）。ダリウスは Sandia の17m試験機（ローター直径17m・高さ21m・
  H/D≈1.24）を既定とし、翼は赤道部の直線区間（高さの15%）と半径 高さの30% の円弧を
  つないだ SLCA（Straight-Line-Circular-Arc）でトロポスキーンを近似する
  （r=R·sin(πf) の一発曲線だと赤道が尖ったレンズ形になるため差し替えた）。
  直線翼は200kW級のH型が直径26m・高さ24mで、弦長は直径の0.13を上限に取る（26m→4マス）。
  φ型の弦長はソリディティ σ≥0.08 を満たす値、サボニウスは弦1固定。主軸は直径の5%以上。
  ヘリカルは直径6m・高さ10m、サボニウスは直径6m・高さ12mで重なり比0.15。
  直径12m未満は機械室を置かず1×2の制御盤に落とす。サボニウスは3段に分けて
  360/(枚数×段数) 度ずつずらす。いずれも浮体式（スパーブイ）に切り替えられる。
  SeaTwirl の30kW機は直径10m・全高31m・水面上13m（水面下18m）、
  浮遊軸型 FAWT はロータ径9.3m・浮体径1.7m。ダリウスにはガイワイヤを付けられる
- [x] 水車(`water_wheel`) — 上掛け／胸掛け／下掛け。上掛けの実施例で水輪 直径3m・
  ブレード幅2.5m、胸掛けで直径3.0m・内幅0.4m、Laxey Wheel は直径22.1m・幅1.8m・
  バケット192個。水車小屋は五間×二間半（9m×4.5m）で軸が壁を貫いて中へ入る。
  導水路は4マスおきに支柱を川床まで落とす。水は `minecraft:water`
- [x] サイロ(`silo`) — コンクリート製の円型は直径1.5〜6m・高さは直径の2.5〜3倍。
  600tのセメントサイロはスカート支持で直径6.4m×高さ20.1m。下部ホッパー・投入シュート
- [x] 給水塔(`water_tower`) — 千葉高架水槽は内径11m・有効水深5m・容量475m³・
  満水位標高50m、中央昇降路は直径約2m。点検デッキ・航空障害灯
- [x] タンク(`tank`) — 10万バレル級で直径39m×高さ20.7m、円錐屋根の勾配1/16以下が
  放爆構造の条件（直径15m以上・高さ9m以上）。風止めリング・らせん階段（踏面2・約26.6度）・
  防油堤（高さ0.5m以上、側板からタンク高さの1/3〈直径15m未満〉または1/2〈15m以上〉）

## 生成器の作り

縦型容器3件は回転体の幾何（`InR`／`Disc`／`Ring`／`Revolve`）を `IndustryExpander.cs` に
共通化し、`IndustryExpander.Vessel.cs` の3ビルダーが呼ぶ。屋根の段数は
`IndustryExpander.RoofLevels` を UI からも呼ぶので、桁橋で起きた「UIと展開側で式が
二重になる」状態を作っていない。

回転体は canonical で回転面を x-y 平面に置き、facade_face で回す。
`IndustryExpander.Face` の east/west の取り違えを修正済み。

### 昇降設備

実際に登れる形にする。外部ラダーは `minecraft:ladder` を胴板の外側1マスへ
1列置き、`facing` は「取り付く壁から梯子へ向かう向き」（+z 側なら south）を入れる。
らせん階段は平ブロックと階段ブロックを交互に置き、平ブロック天端→階段の半段→
一つ上の平ブロック天端と 0.5 ずつ上がるのでジャンプなしで登れる。円周をたどる経路は
斜めに飛ぶ箇所へ直交1マスを挿し込んで直交化してから階段を置く（斜めのままだと段が
繋がらない）。`facing` は進行方向。タンクは階段が +x〜+z の弧を使うので梯子を -z 側へ逃がす。
ブロックステートは `GeneratedBlock.Properties` へ入れ、`facadeface` の回転時は座標の写像
(x,z)→(-z,x) に合わせて east→south→west→north の順に送る。

梯子と開口部は別方角を既定にして塞がないようにしている。
