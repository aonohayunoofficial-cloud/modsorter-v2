# 建築物 / 発電所（`building` / `power_plant`）

親: [../ROADMAP.md](../ROADMAP.md) ｜ 進捗: 6/6 完了

発電所は1つの箱で表せないため、港・空港・駅と同じ粒度で構内を単体構造物へ分解し、
それぞれを小分類として登録する。

## 小分類

- [x] ボイラー建屋(`boiler_house`) — 汽力の高い側の棟。既定 高さ40・作業床4層、
      煙道の張り出し、外部鉄骨、屋上まで通る点検ラダー
- [x] タービン建屋(`turbine_hall`) — 実施例で長さ60m×幅36m×高さ32m（別例 83m×83m×36m）。
      柱スパン9m、天井走行クレーン、機側の低層アネックス
- [x] 煙突(`stack`) — 新仙台火力の実施例で高さ100m・外径5.7mが2本。既定は高さ120・
      基部直径14→頂部6のテーパーに内筒2本、20mごとの踊り場、高さ60以上で航空障害灯
- [x] 冷却塔(`cooling_tower`) — 自然通風の双曲線形。実施例で全高190m・基部半径65.25m・
      喉部42m・頂部43.45mなので喉部は全高の3/4に置く。基部はレイカー柱24本、
      下部に散水盤と貯水池
- [x] 格納容器(`containment`) — PWRは直径40m級の円筒＋ドームで壁厚2・エアロック・補助建屋、
      BWRは矩形の原子炉建屋で燃料取替床と天井クレーン
- [x] 開閉所(`switchyard`) — 門型構造4基を等間隔、三相の母線、防火壁つき変圧器2台、
      フェンスと制御建屋

## 生成器の作り

幾何は `IndustryExpander.Power.cs`、パラメータは `StructureSpec.Power.cs` と
`PowerPlantParamsControl.cs`。回転体は縦型容器3件と同じ `Disc`／`Ring`／`ShellDisc` を使う
（[building-industry.md](building-industry.md) の「昇降設備」も共通）。
