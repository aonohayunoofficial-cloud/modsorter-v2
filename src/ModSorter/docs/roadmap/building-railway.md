# 建築物 / 鉄道（`building` / `railway`）

親: [../ROADMAP.md](../ROADMAP.md) ｜ 進捗: 5/5 完了

駅は「集合体」ではなく、それを構成する単体構造物を小分類として登録する。
すべて建築限界（直流電化 高さ5700mm・幅3800mm）を侵さない位置に取り付けてある。

## 小分類

- [x] 駅舎(`station_building`) — 地平/橋上/高架下の3形式、コンコース天井高はみなし規定
      3.0m以上（橋上の実施例5.5〜6.8m）、改札通路は機械2マス＋通路幅で並べ幅広通路は
      有効幅90cm以上、自由通路の幅員4m、エレベーターはかご内法 幅140cm×奥行135cm
      （11人乗り）に壁を足して3マス角のシャフト
- [x] プラットフォーム・単式/相対式/島式(`platform`) — 縁端は軌道中心から1.5m（実物1475mm）、
      天端はレール面上1.1m≒1マス、ホーム長＝20m車×両数、点状ブロックは縁端から1マス内側、
      ホームドアは20m車4扉＝5m間隔、ホーム端の勾配、高架（柱スパン10m級）
- [x] ホーム上屋(`platform_canopy`) — 軒高はホーム面上4m級（駅区間は軌道から上屋まで6.5m）、
      柱間隔5m（古レール上屋は約4.5m＝5ヤード）、柱はホーム縁端の1マス内側でホーム限界
      1.80mを外す、軒を出すときは建築限界（軌道中心±1.9m・高さ5.7m）回避のため軒高6以上、
      切妻/片流れ/陸屋根/アーチ、雨とい、照明
- [x] 跨線橋(`overpass`) — 桁下はレール面上6以上（建築限界5700mm）、通路幅3m級、
      階段は蹴上げ1マス固定で踏面2＝約26.6度（実物は蹴上げ0.16m/踏面0.30m＝約28度）、
      階段幅は誘導基準140cm以上、両端/片側/なし、腰壁、屋根、中間橋脚
- [x] 車庫(`depot`) — 8両編成180m（線路長＝両数×車長＋余裕）、線路間隔5m級（本線4.0mより
      広く作業通路を取る）、有効高さ8（電車線5.00m＋懸吊0.5m＋余裕0.2m＝限界5.70m）、
      検車ピット深さ1（実物1.2m級・検車エリアの床を線路より1段低くする）、
      屋上点検ホームは車両屋根上3.6m、線路ごとの扉開口、採光帯、2階建の事務所棟

## 生成器の作り

- 軌道は道床だけで表しレールは置かない。`minecraft:rail` は隣接から shape が決まる機能
  ブロックで、shape を書かない生成物では曲線状態を拾って斜めに描かれる。
  また1マス=1m では軌間1067mmが1マス未満で2条にも分けられない。

## 寸法データ（出典）

- ホーム高さはレール面上1100mm（電車専用）・920mm（電車列車共用）・1250mm（新幹線）
- ホーム縁端は軌道中心から1475mm（JR在来線）
- ホーム幅の下限は島式3.0m・相対式2.0m、通勤駅の実際は5〜10m級
- 縁端警告の点状ブロックは縁端から80cm以上離す、島式で向かい合う内方線の中心間は60cm以上
- ホーム長は20m車×両数で10両200m強
- 軌道中心間隔は在来線4.0m・新幹線4.3m
- 建築限界は直流電化で高さ5700mm・幅3800mm（軌道中心から左右1900mm、
  レール面上4300mmが基礎限界）
- 軌間1067mm・1435mm
- ラーメン高架橋の柱スパンは8〜10m級
- 駅の階段は蹴上げ16cm以下・踏面30cm以上・幅140cm以上
