# 船体 / 商船（`hull` / `merchant`）

親: [../ROADMAP.md](../ROADMAP.md) ｜ 進捗: 2/2 完了

## 小分類

- [x] 客船(`liner`) / [x] 貨物船(`cargo`)

既定値は `HullPresets.Merchant.cs`。

## UI上限の引き上げ（この中分類で実施）

全長スライダーの上限を 64 → 140 マスへ、型幅を 24 → 32、深さを 16 → 24 へ上げた。
商船は実物が100m級で、64マスでは実物の主要目を入れられずKPI2を満たせない。
`HullExpander.Form` はもとから 4〜400 を許すので、上げたのはUI側の上限だけ。
全長100マス級ではブロック数が1万を超える（貨物船で約12,000）ため、
生成に時間がかかることをスライダーの注記へ入れた。

## 実物研究と既定値

### 客船(`liner`)

SS グレート・ブリテン（1845・世界初の大型スクリュー客船、ブリストルで保存）の
全長322ft＝98m・型幅50ft6in＝15.4m・喫水16ft＝4.9m・3,400t・
乗客252人を既定（全長98・型幅15・深さ10・喫水5）。深さは喫水5に乾舷5を足した10。
鉄船なので外板は灰色のコンクリート、フレームは鉄。船橋楼は白・煙突は黒。
実船は煙突1本＋帆装用マスト6本の機帆船だが、生成器のマスト間隔が詰まりすぎる
ため4本で近似し、帆は平常時に近い「畳む」を既定にした。
客室は甲板の下なので船楼を持たず、船体中央に3層のデッキハウスと高さ5の煙突。

### 貨物船(`cargo`)

リバティ船（EC2型・1941〜45年に2,710隻建造）の全長441ft6in＝134.57m・
型幅56ft10.75in＝17.34m・深さ37ft4in＝11.38m・満載喫水27ft9.25in＝8.46m・
載貨重量10,856tを既定（全長135・型幅17・深さ11・喫水8）。貨物艙は5つで
艙口・コーミング・デリックを持ち、船体中央に3層の船橋楼と高さ4の煙突。
船首楼・船尾楼を持つ三島型なので船尾楼2・船首楼2・前後長12%。
溶接鋼船なので竜骨の張り出しは0、船底は箱に近い断面85、シアは60%と浅い。
マストは持たずデリックの柱だけなので `Masts = 0`。

## デッキハウス（船橋楼）・煙突・貨物艙の作り

- デッキハウスは船体中央に載る箱で、船首・船尾の端に載る船楼（`BuildCastle`）とは
  別に作る。前後長は全長に対する%で、位置は「前後の位置」でずらす。
- 箱の幅は範囲内でいちばん狭い甲板から両舷1マスずつ引いた値。いちばん広い
  ところを取ると船体の細るほうで舷から張り出し、実船のサイドデッキ（人が前後に
  通る通路）が消える。船楼が「いちばん広い甲板幅」を使うのとは逆向きの決め方で、
  船楼は船尾材の上へ張り出すのが実物、デッキハウスは舷内に収まるのが実物。
- 1層は床1マス＋内法2マスの3マス（実船の階高7ft6in＝2.3m）。上の層は前後を
  1マスずつ詰めるので、下の層の屋根が前後で歩ける甲板になる。
- 窓は各層の内法の下段へ、舷側と前面に入れる。戸口は各層の後面の中央に幅1・
  高さ2で開き、脇に外舷梯子が付く。
- 煙突は箱の後ろ1/3の位置から3マス角で立ち、中心が煙路（頂は開けたまま）。
  高さは屋根から上へのマス数で、実船の水面上17m級に合わせて4〜5を既定にした。
  層数が0のときは屋根の高さが決まらないので煙突も立てない。
- 貨物艙口は甲板を抜いて周りに1マスのコーミングを立てる。幅は型幅の1/3級で、
  両舷に2マス以上の通路が残る幅へ抑える。前後長は艙の間隔の2/3で、残りは
  甲板として歩ける。デッキハウスと重なる位置の艙口は置かない。
- デリックは艙口の前後に高さ8の柱を立て、腕木を頂の1つ下から艙口の中央へ向けて
  1マスごとに1段下げて倒す。

## 商船の残課題（生成器側）

- スクリュー・プロペラと軸を持たない。実船は船尾の水線下にプロペラと舵が並ぶ。
  中心線舵は `z = -1` に立つので、その前（z=0 の水線下）へ置ける余地はある。
- 救命艇とダビット（吊り出し装置）を持たない。実船の客船はデッキハウスの
  両舷に並び、外観の目立つ部位になる。
- 手すり（オープンレール）を持たない。舷墻はブルワークとして塗り壁で立つので、
  柵状の手すりが並ぶ近代船の舷側になっていない。
- 客船の階段室・煙突の周りの通風筒（ベンチレーター）も未再現。
- 全長140マスのとき `StructureNbtWriter` が書く .nbt のブロック数が1万を超える。
  読み込み側（構造ブロックは48³が上限）で扱えるかは未確認。
