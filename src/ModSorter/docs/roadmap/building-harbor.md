# 建築物 / 港湾（`building` / `harbor`）

親: [../ROADMAP.md](../ROADMAP.md) ｜ 進捗: 9/9 完了

国交省 港湾空港部 分類準拠。港は「集合体」ではなく、それを構成する単体構造物を
小分類として登録する。将来これらを並べて配置すると結果的に港になる。

## 小分類

- [x] 岸壁(`quay`) / [x] 桟橋(`pier`) / [x] 防波堤(`breakwater`) / [x] 上屋・倉庫(`transit_shed`)
- [x] ドライドック(`drydock`) / [x] ガントリークレーン・コンテナクレーン(`gantry_crane`)
- [x] 橋形クレーン(`bridge_crane`) / [x] 係船柱(`bollard`) / [x] 灯台(`lighthouse`)

## 生成器の作り

平面主体の構造物（岸壁・桟橋・防波堤）は箱ベースを通さず `HarborExpander.cs` が
座標リストを直接返す（`StructureExpander.Civil.cs` の系統に倣う）。

- ガントリークレーンのブーム起伏を実機準拠 0〜84度に修正済み。
  ラチスブームの実用上限70〜80度、STS の格納姿勢がほぼ上端。

## 寸法データ（出典）

- ガントリークレーンのブーム起伏角 0〜84度（実用上限70〜80度）
