# 建築物 / 橋梁（`building` / `bridge`）

親: [../ROADMAP.md](../ROADMAP.md) ｜ 進捗: 4/4 完了

## 小分類

- [x] 桁橋(`girder_bridge`) — 桁高は支間長の1/20級（連続桁はさらに8割）、3径間連続の
      側径間:中央径間＝1:1.25、主桁間隔3m級、車線幅3.25〜3.5m、歩道2.0m級、高欄1.1m、
      照明の灯具間隔30m級、橋脚は張出式(T型)/壁式/ラーメン。単純桁は支点で桁を切って
      遊間を入れる。床版と路面は1マス=1mの丸めで2層になる（実寸は合わせて0.3m）
- [x] 吊り橋(`suspension_bridge`) — サグ比1/10級（安芸灘大橋 74.0m/750m）、側径間は
      中央径間の20〜60%（既定40%）、ハンガー間隔10〜20m級（明石海峡大橋14m）、
      主塔は門型/H型/トラス塔で床版上の高さはサグ＋余裕、補剛桁高は実橋の支間1/100級が
      1マス=1mで潰れるため最小2マス。ケーブル面と主塔は床版の外側（x=-1/W）に置くので
      車道の幅に影響しない。アンカレイジは取付部を兼ねる
- [x] アーチ橋(`arch_bridge`) — ライズ比1/5〜1/10（既定1/5）、上路式/下路式/中路式、
      上路式はリブが床版の下で支柱受け、下路式はリブが床版の外側で吊材吊り、
      タイドアーチのタイ材と横構を選択可。起拱部は推力を受けるため床版より広い基礎を置く
- [x] 跳開橋(`bascule_bridge`) — 固定トラニオン式、単葉/双葉、跳開角0〜70度
      （勝鬨橋は70秒で70度まで開く設計）、可動桁は0.25マス刻みで階段状に積む、
      釣合い錘はトラニオン後方の腕に付き開くほど橋脚内のピットへ降りる、
      機械室は主橋脚の上・路肩の外側。照明は可動桁には立てない

## 生成器の作り

桁橋で確定した横断構成（車線／中央分離帯／区画線／地覆／歩道／高欄）は
`BridgeExpander.Deck.cs` の `MakeSection`／`BuildDeckSurface` に共通化し、
吊り橋・アーチ橋・跳開橋はこれを呼ぶ。

**桁橋だけは先に書いたため同じ割り付けを自前で持っている（式を直すときは両方を直す）。**

## 寸法データ（出典）

- 桁橋の適用支間は25〜150m（世界最大支間300m）
- 桁高は支間長の1/20級で連続桁はさらに低くできる
- 3径間連続桁の側径間:中央径間＝1:1.25 が最も鋼重が軽い
  （土木学会 鋼連続合成桁の設計法に関する検討）
- 主桁間隔3m級／床版厚0.22m・舗装厚0.08m
- 車線幅3.25〜3.5m／歩道幅2.0m級で車道との段差（地覆）0.15〜0.25m
- 高欄1.1m／区画線の幅0.15m
- 道路照明の灯具間隔30m級（道路照明施設設置基準、橋長50m以上で連続照明）
- 橋脚は張出式（T型）が最も一般的、幅員が広い橋では壁式
- サグ比1/10前後（安芸灘大橋 サグ74.0m・中央支間750m）
- ハンガー間隔10〜20m級（明石海峡大橋14m）
- アーチのライズ比は支間の1/5〜1/10
- タイドアーチの適用支間50〜170m・世界最大は支間550m（上海盧浦大橋）
- 跳開橋は70秒で70度まで開く設計（勝鬨橋）
