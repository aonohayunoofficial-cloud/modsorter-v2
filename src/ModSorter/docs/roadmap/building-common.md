# 建築物 / 共通事項（`building`）

親: [../ROADMAP.md](../ROADMAP.md) ｜ 進捗: 50/50 完了

## 平面土木構造物の扱い

滑走路・誘導路・エプロン・桟橋・防波堤・岸壁などの平面主体構造物も建築グループ内に
登録する（ユーザー確定）。パラメータ設計は箱ベースと別系統（長さ・幅・厚み・付帯設備の有無）とし、
生成も `StructureExpander.Civil.cs` に倣って専用 Expander が座標リストを直接返す
（港湾系は `HarborExpander.cs` で実施済み。空港系は `AirportExpander.cs` を新設予定）。

## 共通パラメータ（建物系）

幅・奥行き・高さ・階数・屋根形式・屋根勾配(roof_pitch)・軒の出(eave_overhang)・
軒面選択(N/S/E/W)・開口配置・煙突(本数/高さ/太さ/貫通/寄せ)

## 屋根形式マスター（Minecraft wiki 準拠）

- 平屋根[済] / 片流れ(shed)[済] / 切妻(gable)[済] / 切妻階段(gable_stairs)[部]
- 寄棟(hip) / 半寄棟 / サルトボックス / ダッチゲーブル / ギャンブレル / マンサード
- ヘルム(塔用) / 四角錐ピラミッド(pyramid)[済・UI接続済] / ドーム(dome)[部]
- 鋸屋根(sawtooth・工場)[済] / モニター屋根(monitor・工場)[済]

## 継続項目（小分類の網羅とは別枠）

- 屋根形式追加（hip/ギャンブレル/マンサード/ヘルム 等）
- 大型シャッター

## 未解決の判断事項（建築物にかかるもの）

- 非矩形フットプリント×勾配屋根の制約（現状 flat へ強制フォールバック）
- 可動メタ（`Properties` の axis/facing）を跳開橋・風車・水車でどこまで使うか
- 空港ターミナル系（旅客/貨物）を建物系の箱ベースに寄せるか、専用Specにするか
