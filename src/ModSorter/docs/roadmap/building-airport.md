# 建築物 / 空港（`building` / `airport`）

親: [../ROADMAP.md](../ROADMAP.md) ｜ 進捗: 9/9 完了

国交省 空港土木/建築施設 分類準拠。空港は「集合体」ではなく、それを構成する単体構造物を
小分類として登録する。

## 小分類

- [x] 管制塔(`control_tower`) — 管制室22〜130㎡、窓は鉛直から外へ15度、外周キャットウォーク
- [x] 旅客ターミナル(`passenger_terminal`) — ゲート間隔＝エプロンのスポット幅、奥行き26〜30m、
      2層、アプロンドライブ式搭乗橋（伸長15〜45m・勾配10%以下）
- [x] 貨物ターミナル(`cargo_terminal`) — 約155㎡に1台のトラックドック、ドック高さ1.2m、
      庫内有効高さ7〜12m、エアサイド大型扉、2層の事務所棟
- [x] 格納庫・ハンガー(`hangar`) — 扉幅＝翼幅＋クリアランス、扉高さ＝尾翼高さ＋1m、
      NFPA409の区分（28ft・2026年改訂で35ft）を明示、アーチトラス・引き分け戸
- [x] 滑走路(`runway`) — コード別に幅23/45/60m、中心線・接地帯・進入端標識
- [x] 誘導路(`taxiway`) — コード別に幅10.5/18/23/25m、ショルダー込み全幅25/44/60m
- [x] エプロン(`apron`) — スポット幅＝翼幅＋クリアランス、スポット数ぶん横に並べる
- [x] 進入灯(`approach_light`) — CAT I 900m・CAT II/III 側方列270m・簡易式420m、
      灯数で距離が読める段構成、バレット時のクロスバー削減、進入灯橋、PAPI
- [x] ヘリポート(`helipad`) — D値からFATO 1D・TLOF 0.83D・セーフティ3mか0.25D、
      TD/PM円 内径0.5D、H標識、緑の縁灯 間隔5m以下、高架式

## 生成器の作り

土木3件（滑走路・誘導路・エプロン）は `AirportExpander.cs` が座標リストを直接返す。
建築5件（管制塔・旅客/貨物ターミナル・格納庫）と進入灯・ヘリポートも同ファイル。

## 寸法データ（出典）

- 滑走路 幅45m級・中心線・接地帯標識・進入端標識
- 誘導路 幅23m以上・ショルダー9.5m
- エプロン スポット単位の駐機区画
- 管制室の床面積 234・350・625・850 sq ft＝22・33・58・79㎡（FAA Order 6480.7D）、
  羽田の新管制塔は約130㎡・塔高113m級
- 管制室の窓は鉛直から外へ15度
- 管制室の平面形は正方形・五角形・六角形・八角形・円形（八角形が最多）
- 管制室の外周に窓清掃用のキャットウォーク（幅1m級）
- ゲート1つあたりの桁行きは平均33〜40m、ピア全長210〜300m（FAA AC 150/5360-13）
- ダブルローデッドの動線幅30ft（約9m・動く歩道なし）、ラウンジ奥行き25〜30ft（8〜9m）
- 出発が上階・到着が下階の2層構成
- アプロンドライブ式搭乗橋は伸長15〜45m、ロタンダ高さ5m級（最大8m）、勾配10%以下
- トラックドックは建物床面積1,000sq ftあたり0.6台（旧0.3台）＝約155㎡に1台、
  扉は幅9ft・高さ10ft、ドック高さ48インチ（1.2m）、建物の面から取付道路まで150ft（約46m）
- 庫内有効高さは22ft（約7m）が従来標準・自動段積みで40ft（約12m）
- 事務所は倉庫面積の10%／エプロンは建物床面積の4.5倍、敷地は建物15%・ランドサイド25%・
  エアサイド60%
- 貨物機の所要ランプはコードC 2,300平方ヤード・D 3,900・E 6,500・F 8,650
- 格納庫の扉高さはNFPA409で28ft（8.5m）超がGroupI・2026年改訂で境が35ft（10.7m）へ
- 尾翼高さはCRJ200 6.2m・A320 11.8m・B777 18.5m・A380 24.1m、扉高さは尾翼＋1〜1.5m
- A380対応格納庫の実例は幅45m×奥行62m×有効高さ18m
- 進入灯CAT Iはセンターライン900m・間隔30m、クロスバー150/300/450/600/750m、
  300mのものが長さ30mで他は外縁が進入端の300m先で収束、0〜300m:1灯・300〜600m:2灯・
  600〜900m:3灯／CAT II/IIIは270mまで赤の側方列／簡易式は420m・間隔60m・300mに
  長さ18mか30mのクロスバー1本／バレットは簡易式3m以上・他4m以上で、使うとクロスバーは
  CAT I 1本・CAT II/III 2本に減る
- ヘリポートはD値基準でFATO 1D（限定用途0.83D）・TLOF 0.83D・
  セーフティエリアは3mか0.25Dの大きい方、TD/PM円は内径0.5D、
  H標識はD<16mで高さ3m、TLOF縁灯は緑・間隔5m
