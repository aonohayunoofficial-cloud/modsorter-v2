## 小分類

- [x] スループ(`sloop`) / [x] スクーナー(`schooner`) / [x] クリッパー(`clipper`)

既定値は `HullPresets.Modern.cs`。

## 実物研究と既定値

### スループ(`sloop`)

ハドソン・リバー・スループ。復元船クリアウォーターの甲板長76ft＝23m・
型幅25ft＝7.6m・喫水8ft＝2.4m・帆面積4,305sq ft＝400m²を既定（全長23・型幅8・
深さ4・喫水2）。河川の浅瀬を走る貨物船なので長さ/幅3:1と幅広、船底は平底寄りで
断面75、船尾は幅の広い角形トランサム45%。帆装は1本マストのガフ帆（縦帆）で、
マストは甲板上26mと船体長より高い。船楼を持たず甲板は平ら。

### スクーナー(`schooner`)

グランドバンクスの漁業スクーナー。ブルーノーズ（1921）の全長143ft1in＝43.6m・
水線長34.1m・型幅26ft11in＝8.2m・喫水15ft11in＝4.85m・258tを既定
（全長44・型幅8・深さ6・喫水5）。深い喫水と入角12度の細い水線で風上へ切り上がる
船型。2本マストの縦帆で、実物は主檣が甲板上126ft＝38.4m・前檣102ft8in＝31.3mだが、
現状の生成器は全マストを同じ高さで立てるので中間の34を取る。船体は黒く塗るので
ダークオーク。

### クリッパー(`clipper`)

茶クリッパー。カティサーク（1869）の船体長212.5ft＝64.77m・型幅36ft＝10.97m・
艙深21ft＝6.40m、満載喫水20ftで排水量2,100t・帆32,000sq ft＝3,000m²を既定
（全長64・型幅11・深さ8・喫水6）。全長は生成器の上限64マスにちょうど
収まる。長さ/幅6:1・角柱係数0.628とクリッパーのなかでも最も痩せた船体で、水線は
船首で内へ凹む（船首の肥え15・入角10度）。3本マストの横帆、主檣は甲板上47m
（スカイセイル桁44.5m）・主檣下桁23.8m。

## 縦帆（ガフ帆）の作り

- ブームの高さは帆を張る範囲すべての station の甲板を見て決める（`DeckY+舷墻+2`
  の最大値）。マストの位置だけで決めると、シアで持ち上がる船尾側の甲板・舷墻・
  舵柄へブームが食い込む。ブームの下は2マス空くので人が通れる。
- 帆の後端は、後ろにマストがあるときは2本の間隔の1/3を空けて止める。実物の
  ブルーノーズの前ブーム9.9m／マスト間隔15m級の比に合わせた。空けないと帆が
  後ろのマストへ張り付く。
- 最後尾のマストの帆は船尾材の手前2マスで止める（z=0〜1 は中心線舵の舵柄、
  z=-1 は舵頭の場所）。ここを空けないと帆が舵とぶつかる。
- ガフはスロート（マスト側の前端）よりピーク（後端）を持ち上げ、帆は後ろへ行く
  ほど背の高い四角形になる。立ち上がりは張る長さとマスト頂までの余りの小さい
  ほうで、実船と同じ水平から30〜45度に収まる。1マス上がるところは段差の下も
  桁材で埋め、桁が角でしか接しない飛び石にならないようにする。
- 生成結果の帆面積: スクーナー（ブルーノーズ）は主帆 約338m²・前帆 約265m²で、
  実物は主帆386m²・総帆面積930m²（ジブとトップスルを含む）。
  スループ（クリアウォーター）は主帆 約195m²で、実物の総帆面積は400m²。

## 帆装の残課題（生成器側）

- 横帆は1本のマストにつき1枚しか組めない。実物のクリッパーは下桁から上へ
  コース・ロワートップスル・アッパートップスル・ゲルンスル・ロイヤルの5段を張り、
  桁は上へ行くほど短くなる（カティサークで23.8→20.7→19.5→14.6→11.6m）。
  現状は丈30の1枚で段の合計を近似している。多段化は Sail.cs 側の課題。
- 帆桁が舷の外へ出るぶんが `HullExpander.Extent` の幅に入っていない。
  カティサークの帆桁24に対し型幅11なので左右6マスずつ外へ出るが、外寸表示は
  船体幅のままになる。生成物自体は `Normalize` が負座標を寄せるので欠けない。
  `Form.Bounds` が x の最小・最大を返すようにして帆桁と突き合わせるのが直し方。
- 縦帆のブームは船尾材より後ろへ出せない。実物のブルーノーズの主ブームは24.7mで
  船尾から張り出すが、外寸と生成物を食い違わせないため船尾材の手前で切っている。
  生成物の主帆は13マスぶんの長さになる。
- 船首の三角帆（ジブ）とマスト間の三角帆（ステイスル）を張っていない。実船の
  スループ・スクーナーは船首斜檣からジブを張り、総帆面積の3〜4割を占める。
  船首斜檣（バウスプリット）は `PutHead` が z 方向へ出せないので、その張り出しと
  合わせた課題として残す。
- 「畳む」を選ぶと縦帆の船でも横帆の帆桁が1本渡る。畳んだ縦帆はブームの上へ
  巻き束ねた形なので別物。帆の種類と張り／畳みを1つの値で持っているのが原因で、
  分けるときは `hull_sail` に畳み方を足す。
- 全マストを同じ高さで立てるので、主檣と前檣に高低差のある船は中間値で近似している。
